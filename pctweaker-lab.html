Separate ping from FPS

A browser page cannot reliably reproduce a game's server route or packet behavior. Use real measurements, then use these tools to interpret them.

NO FAKE LIVE DATA
PingRound-trip latency to a destination. Compare the same region/server when testing a routing change.
JitterVariation in latency. A low average ping can still feel inconsistent when latency fluctuates.
Packet lossMissing packets can cause rubber-banding and delayed updates. Test loss separately from FPS.
